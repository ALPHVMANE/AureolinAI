# AureolinAI

AureolinAI is a web-based application that combines language-learning features with an integrated image generator. It provides an interactive experience by merging language practice with visual content creation.

---

## 🚀 What is AureolinAI?

AureolinAI is built primarily with **PHP**, **CSS**, **JavaScript**, and **HTML**.  
The project aims to help users learn languages interactively while also generating images that enhance the learning experience.

---

## 🧰 Tech Stack

- **PHP** – server-side logic  
- **HTML / CSS / JavaScript** – UI and client-side experience  
- **Composer** – dependency management  
- Follows a structured layout including folders such as:
  - `src/`
  - `public/`
  - `templates/`
  - `config/API/`
  - And more

---

## ✅ Features

- Interactive language-learning interface  
- Built-in image generation capability (API-driven)  
- Web-based UI accessible from any browser  
- Environment-based configuration for API keys and system behavior  

---

## 📦 Installation & Setup

```bash
# Clone the repository
git clone https://github.com/ALPHVMANE/AureolinAI.git
cd AureolinAI

# Install PHP dependencies
composer install

# Create your environment file
cp .env.example .env
# Then fill in your API keys and configuration details

# Ensure your server (Apache/Nginx) points its document root to the /public directory
